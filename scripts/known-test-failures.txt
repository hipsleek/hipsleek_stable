# scripts/local-ci.sh compares the set of failing targets from a full `dune test`
# against this list:
#
#   * a failure NOT listed here  -> a new regression, the run fails
#   * a listed target that PASSES -> it was fixed, remove the line (the run fails
#                                    so that the list cannot silently rot)
#
# This file deliberately records reality instead of promoting the cram baselines,
# so that these known divergences stay visible rather than being rewritten into
# `run.t` as if they were the expected output.
#

# those provers are skipped by dune (see the bin-available guards in
# dune-tests/*/dune), so an environment that HAS them may surface additional
# failures that are not listed here.
#
